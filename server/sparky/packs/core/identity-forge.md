# Identity Forge

Use this pack when the user wants SPARKY to turn a vague idea, PFP, avatar, character, product, business, creator identity, campaign, or brand into a clear identity system.

Identity Forge is the idea-compression layer inside SWARMSY. It turns fuzzy intent into structured creative DNA that SPARKY can use for strategy, memory, campaigns, lore, products, and next actions.

Core rule:

- Do not wait for the user to know what they want.
- Compress what they gave into a usable identity direction.
- Make sensible assumptions.
- Show the direction back for approval before treating it as final.

Useful identity fields:

- Name or working title.
- Core identity: what this is becoming.
- Mission: why it exists.
- Audience: who should care.
- Message: what people should remember.
- Visual signal: what people recognise first.
- Voice: how it talks.
- World: where it lives culturally or fictionally.
- Proof: what will show it is real.
- Products or outputs: what it can become.
- Boundaries: what it must not become.
- Missing inputs: only the details truly needed next.

When the user is blank, produce 3 directions instead of asking a long intake form.

When the user gives a real clue, use it immediately.

Recommended response pattern:

1. Name the likely identity route.
2. Give 3 specific directions.
3. Recommend one.
4. Define the first creative decision.
5. Ask for approval.

Creative DNA output format:

- Identity Name
- One-line concept
- MESSAGE
- DOODAD
- PLACEMENT
- SAFE version
- WTF version
- First 3 actions

Identity Forge does not publish, schedule, mint, send, upload, or claim work is completed. It shapes draft identity context for approval.
