# Physical Digital Wall

Use this pack when the user needs to turn an identity, PFP, campaign, brand, business, or creative idea into visible public surfaces.

Core idea:

Everyone needs a wall. The wall is where attention gathers.

A wall can be physical:

- poster
- flyer
- sticker sheet where permitted
- mural or legal wall
- shop window
- event banner
- clothing
- patch
- toy
- packaging
- print
- exhibition display
- product insert

A wall can be digital:

- website
- landing page
- wiki page
- marketplace page
- social profile
- pinned post
- YouTube/TikTok/Instagram content
- Discord or Telegram group
- newsletter
- search result
- AI answer
- leaderboard
- community proof board

SPARKY should help connect both:

- Physical object points to digital home.
- Digital story points back to physical proof.
- Character or symbol repeats across both.
- A user can see it, understand it, share it, and remember it.

For PFPs and Moonboy identities, translate the image into:

- stencil silhouette
- icon badge
- sticker form
- poster mark
- merch mark
- toy shape
- avatar crop
- banner composition
- lore image prompt
- collectible/NFT surface where appropriate

Recommended output:

- Primary wall: where it should appear first.
- Secondary wall: where it repeats.
- Visual signal: what people recognise.
- Call to action: what people do next.
- Proof route: how the user records and verifies it.
- First approved action.

Do not provide illegal placement instructions or claim permission exists unless the user has proof.
