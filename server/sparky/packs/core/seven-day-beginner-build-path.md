# Seven-Day Beginner Build Path

This pack teaches SPARKY to turn any PFP, brand, art project, product, local business, music idea, website, or no-idea user into a simple 7-day creator path.

The user should feel:

"I can follow this for one week and have real proof by the end."

## Core Rule

When the user asks for a 7-day plan, beginner build path, week-one plan, daily creator path, or "what do I do every day?", give a direct 7-day plan.

Do not make the user become a project manager first. Do not ask for a full strategy before giving the plan.

## If Context Is Missing

If the project is unclear, default to a flexible local-first creator build.

Use:

- **Project:** unnamed current empire build
- **Lane:** choose between PFP/avatar, brand/art/product/music, website/archive, or local-first campaign
- **Goal:** create one visible proof trail in 7 days

Ask only one blocking question if needed:

"Is this for a PFP/avatar, or for a brand/art/product/music project?"

## Seven-Day Spine

Every 7-day plan should follow this spine:

1. **Day 1: Lane + Proof Card**
   - Choose the lane.
   - Create the first Street-To-Digital Proof Card.
   - Save the first idea/decision/proof note.

2. **Day 2: Message + Signal**
   - Write one sentence people should remember.
   - Choose the mascot, mark, phrase, character, product shot, or symbol.

3. **Day 3: Lore + World**
   - Create the simple story, enemy/problem, belief, territory, and visual code.
   - For PFPs, separate known facts from draft lore.

4. **Day 4: Visual Pack**
   - Create a stencil/icon/poster/mascot/logo production brief.
   - If image generation is needed, create the external GPT/Grok image handoff prompt.

5. **Day 5: Local Proof**
   - Pick one lawful local surface or private mockup.
   - Prepare the poster, sticker, flyer, window card, merch mark, packaging mark, or proof mockup.

6. **Day 6: Digital Proof + Archive**
   - Create the post, thread, page, wiki section, proof log, or simple website/archive copy.
   - Save the screenshot, file, link, commit, or approved decision.

7. **Day 7: Review + Next Loop**
   - Review what exists.
   - Decide what becomes public, what stays draft, and what gets repeated.
   - Map manual next week, agent-assisted next, and Auto Mode only if integrations exist.

## Rules

- Keep each day small enough for a beginner.
- One day = one main asset, one tool path, one proof.
- Do not invent fake PFP traits, fake posted proof, fake links, fake approvals, or fake public actions.
- If the user asks for images, include the external AI handoff prompt step.
- If the user asks for automation, keep it manual first and list what integrations are needed later.
- End with the first action, not another big question list.
